3. **[P2] Give the pulse sparkline an explicit source scope or honor the selected channel.** The selected overview and recent day summaries come from `NativeHealthHistory.load(query)`, which uses `query.channel`. The new seven-day trend in `HealthDashboardViewModel.kt:294` always reads channel `journal`, irrespective of that selection. Its subtitle only says “daily average heart rate”, while clicking opens `HealthRecordBrowser` for `state.historyChannel`. On Samsung/HC/BLE-specific views the tile, curve and opened records can therefore describe different datasets, without indicating the distinction. Either query the chosen channel or label the curve as the merged journal and open matching detail. Missing days are correctly retained as gaps; they are not interpolated or filled with zero.
