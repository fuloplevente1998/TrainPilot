1. Hogyan tudod telefonon tesztelni?
Két kényelmes módszered van a telefonos tesztelésre:
A) Azonnali tesztelés a telefonodon (APK fordítás nélkül, PWA módban)
Nyisd meg a telefonod böngészőjében (Chrome vagy Samsung Internet) a fent található Shared App URL-t.
A böngésző jobb felső menüjében (három pont) válaszd a „Hozzáadás a kezdőképernyőhöz” (Add to Home screen) vagy „Alkalmazás telepítése” opciót.
Az app külön ikont kap a telefonodon, és pontosan úgy nyílik meg teljes képernyőn (címsor nélkül), mint egy natív app.
B) Valódi natív .apk build és telepítés GitHub Actions-szel (Automatikus!)
Létrehoztam a projektben a .github/workflows/build-apk.yml automatizációt. Amikor feltolod a változtatásokat a GitHubra:
A GitHub ingyenes felhős szervere (GitHub Actions) automatikusan lefordítja a debug APK-t (./gradlew assembleDebug).
A GitHub repódban az Actions fül alatt megjelenik a build, és egy kattintással letöltheted a kész TrainPilot-debug-apk.zip-et közvetlenül a telefonodra.
Megnyitod a telefonon a letöltött .apk-t, engedélyezed az ismeretlen forrásból való telepítést, és kész is a natív app.
Ha pedig saját gépen szeretnéd lefordítani:
code
Bash
git pull
npm install
npx cap sync android
cd android
./gradlew assembleDebug   # Windows-on: gradlew.bat assembleDebug
A kész APK itt lesz: android/app/build/outputs/apk/debug/app-debug.apk.

3. További ötletek a TrainPilot fejlesztésére
Haptikus visszajelzés (Rezgés a szériák rögzítésekor):
Amikor az edzés közben rányomsz az OK gombra egy széria befejezésekor, egy rövid, 30-40 ms-os diszkrét rezgés (navigator.vibrate(40)) azonnali prémium, fizikai visszajelzést ad anélkül, hogy a képernyőt kellene figyelned.
Audio & Rezgés jelzés a pihenőidőzítő lejártakor:
A pihenőidő (pl. 90 mp) visszaszámlálásakor az utolsó 3 másodpercben lágy hangjelzés, a végén pedig dupla rezgés és csengés. Így edzés közben zsebre teheted a telefont, vagy leteheted a pad mellé.
1RM (One Rep Max) kalkulátor és személyes rekord (PR) jelvények:
Az edzés során naplózott súly és ismétlésszám alapján azonnal számítható a becsült 1RM (pl. Epley vagy Brzycki formulával). Ha új egyéni csúcs születik egy gyakorlatban, egy kis aranyszínű ★ PR animáció jelenhetne meg a széria mellett.
Gyors széria-duplázás és előző súly automatikus előtöltése:
Az új széria hozzáadásakor automatikusan töltse be az előző széria súlyát, hogy ne kelljen minden sorozatnál újra begépelni a kilogrammot, csak egyetlen gombnyomással jóváhagyni.
RPE (Megfeszülés mértéke) / Nehézség skála egyszerűsítése:
A gyakorlat alján lévő 1-5 nehézségi gombok helyett egy letisztult, vízszintes csúszka vagy 3 gyors opció: „Könnyű volt”, „Pont jó”, „Határon voltam (RPE 9-10)”.
