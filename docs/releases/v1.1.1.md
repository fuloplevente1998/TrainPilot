# TrainPilot 1.1.1 / 2699 — Bluetooth investigation candidate

Adds **Settings → Bluetooth watch trial** for the RDFit GT4Pro+ investigation: a bounded foreground BLE scan, explicit device connection, service discovery and a locally verified diagnostic JSON export. If the device offers the standard Bluetooth heart-rate service, an opt-in reader displays fresh live pulse separately from Health Connect.

Discovery does not yet import RDFit sleep, steps or historical pulse. The report is needed to select the actual device protocol. It contains service capabilities rather than Bluetooth addresses, packets or pulse readings. Leaving the screen/backgrounding the app ends the connection.

Includes the existing 1.1.0 / 2698 enhancements. Package ID, storage and original signing identity remain unchanged; versionCode **2699** supports an in-place upgrade. Stable release remains **1.0.9 / 2697** pending physical-phone acceptance.
